## 一、架构

### 做得好的

- 分层清晰：screen → hook → service → db，无越层调用；`useCookingMachine.ts` 组合 7 个子 hook，职责单一（src/hooks/useCookingMachine.ts:26）

- 计时器用 AbortSignal 可打断、无泄漏；TTS 失败静默降级不崩溃

### 问题

- 🟠 **`HeadsetService` / `GestureService` 是从未实例化的 stub**。生产分支直接 `throw ... not yet implemented`（src/services/headset.ts:111, src/services/gesture.ts:95），且全 src 无任何消费方——产品宣称的“优先级 1 耳机按键”和“优先级 4 挥手手势”实际不存在
- 🟡 `api-proxy.mock.ts` 的 `createMockApiProxy()` 仅剩 barrel 导出（src/services/index.ts:5），无实际消费方，属遗留死代码
- 🟡 hooks/index.ts 把全部 7 个内部子 hook 全量导出并注释 "available for direct use if needed"——典型 YAGNI，只有 useCookingMachine 消费它们
