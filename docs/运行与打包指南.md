# 运行与打包指南

## 依赖服务

App 运行需要先启动以下本地后端服务：

| 服务 | 目录                     | 端口 | 启动命令                   |
| ---- | ------------------------ | ---- | -------------------------- |
| STT  | `D:\project\stt-server\` | 5000 | `python server.py`         |
| TTS  | `D:\project\tts-server\` | 4000 | `node local-tts-server.js` |
| LLM  | `D:\project\llm-server\` | 3001 | `yarn start`               |

### 一键启动（推荐）

```powershell
# Windows PowerShell — 启动 STT + TTS，会自动创建/复用 venv
.\scripts\start-services.ps1

# 跳过健康检查
.\scripts\start-services.ps1 -NoCheck

# 跳过 adb reverse
.\scripts\start-services.ps1 -NoAdb
```

```bash
# WSL bash — 同上（自动调用 Windows PowerShell）
./scripts/start-services.sh
```

首次运行自动创建 Windows venv 并 `pip install` 依赖，后续秒开。按任意键统一关闭所有服务。

## 服务地址配置

所有后端服务地址集中在 `src/config.ts`，默认值如下：

```typescript
export const TTS_URL = 'http://localhost:4000';
export const STT_URL = 'http://localhost:5000';
```

- **模拟器 / USB 调试（adb reverse）** — 保持 `localhost` 即可
- **真机独立打包（无 adb reverse）** — 改为电脑的局域网 IP，手机和电脑需在同一 WiFi

## 模拟器运行

### 1. 启动 Metro

```powershell
# Windows PowerShell（Metro 不能在 WSL 中启动）
cd D:\project\cooking-guide
yarn start
```

### 2. 编译安装到模拟器

```powershell
# Metro 未启动时 — 编译 + 安装 + 启动 Metro
$env:SKIP_IOS="true"; yarn android

# Metro 已启动时 — 只编译安装，不重启 Metro
$env:SKIP_IOS="true"; yarn android --no-packager
```

> `SKIP_IOS=true` 跳过 `react-native-audio-api` 下载 iOS 预编译库，省几分钟构建时间。可在 PowerShell profile 中设为全局变量：
>
> ```powershell
> echo '$env:SKIP_IOS="true"' >> $PROFILE
> ```

### 3. ADB 端口转发

模拟器通过 `adb reverse` 访问宿主机上的后端服务：

```powershell
& "C:\Users\fely\AppData\Local\Android\Sdk\platform-tools\adb.exe" reverse tcp:4000 tcp:4000
& "C:\Users\fely\AppData\Local\Android\Sdk\platform-tools\adb.exe" reverse tcp:5000 tcp:5000
& "C:\Users\fely\AppData\Local\Android\Sdk\platform-tools\adb.exe" reverse tcp:8081 tcp:8081
```

或用辅助脚本（自动转发 4000/5000/8081）：

```powershell
node scripts/adb-reverse.js
```

### 4. adb 命令规范

系统 PATH 中可能有多个 adb（如 scrcpy 自带旧版本），**必须使用 Android Studio 的 adb**：

```powershell
& "C:\Users\fely\AppData\Local\Android\Sdk\platform-tools\adb.exe" <命令>
```

### 白屏排查

若 Metro 启动后模拟器白屏：

1. **重新编译安装** — 旧 APK 可能 JS 引擎从未初始化，`yarn android` 重新编译即可
2. **端口转发** — 确认 `adb reverse tcp:8081 tcp:8081` 已执行
3. **Reload** — 模拟器中 Ctrl+M → Dev Menu → Reload
4. **查看日志** — Android Studio Logcat 过滤 `ReactNative` 或 `com.cookingguidern`

## 真机独立打包

无需插电脑、无需 Metro 热重载，打包成独立 APK 安装到手机。

> **已验证**：STT（语音命令识别）+ TTS（语音播报）真机调试已通过（2026-06-17）。手机和电脑在同一 WiFi 下即可正常使用。

### 1. 改服务地址

```powershell
# 查电脑局域网 IP
ipconfig
```

修改 `src/config.ts`：

```typescript
export const TTS_URL = 'http://192.168.x.x:4000';
export const STT_URL = 'http://192.168.x.x:5000';
```

> 电脑和手机需在同一 WiFi 下，电脑上需先启动好后端服务。

### 2. 打包

```powershell
cd D:\project\cooking-guide\android
.\gradlew assembleRelease
```

APK 生成位置：`android/app/build/outputs/apk/release/app-release.apk`

### 3. 安装

USB 线连手机 → 手机通知栏选择「文件传输 (MTP)」→ 电脑上把 APK 拖入手机 Download 目录 → 手机上用文件管理器点击安装。

## 分架构打包

在 android/app/build.gradle 中：
android {
    flavorDimensions "arch"
    
    productFlavors {
        arm64 {
            dimension "arch"
            ndk {
                abiFilters "arm64-v8a"
            }
            applicationIdSuffix ".arm64"
            versionNameSuffix "-arm64"
        }
        x86 {
            dimension "arch"
            ndk {
                abiFilters "x86_64"
            }
            applicationIdSuffix ".x86"
            versionNameSuffix "-x86"
        }
    }
}

## 常见坑

| 问题                                                         | 原因与解决                                                                                                                                                                    |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `yarn android` 失败 — `sdk.dir` 格式错误                     | `android/local.properties` 中 `sdk.dir` 必须使用 Windows 路径（如 `C:\\Users\\...`），不能用 WSL 路径（如 `/mnt/c/...`）                                                      |
| iOS 预编译库下载卡住构建                                     | 已通过 `SKIP_IOS=true` 环境变量拦截。`scripts/clean-ios-deps.js` 在 `postinstall` 钩子中自动执行，检测 Windows 时删除 iOS/macOS 预编译库                                      |
| 从 WSL 运行构建命令                                          | **不要从 WSL 运行** `yarn install` / `yarn android` / `yarn start`。这些命令必须在 **Windows PowerShell** 中手动执行。WSL 不配置 Android SDK 和 JDK，且文件路径转换会导致问题 |
| `yarn android --no-packager` 时还触发 Gradle 重新下载 iOS 库 | 确保当前 PowerShell 窗口中设置了 `$env:SKIP_IOS="true"`。建议加到 PowerShell profile：`echo '$env:SKIP_IOS="true"' >> $PROFILE`                                               |
| 新增原生依赖后 App 白屏/崩溃                                 | Phase 4 新增了 `react-native-haptic-feedback`、`react-native-keep-awake`、`@react-native-community/blur`，必须重新编译：`cd android && .\gradlew clean` 后 `yarn android`     |
| WiFi 延迟抖动影响语音                                        | 2.4GHz 网络下 STT/TTS 偶有延迟抖动，建议使用 5GHz WiFi                                                                                                                        |


## 验证

1. 按压反馈：在 HomeScreen Bento、菜谱列表卡片、分类筛选、设置页点按，应有缩放动画
2. Haptic：按键/卡片点按时手机轻微震动（iOS/Android 支持机型）
3. 烹饪熄屏：进入 CookingScreen 后，屏幕保持常亮；退出后恢复正常
4. 玻璃底栏：RecipeDetailScreen 底部操作栏在 iOS 上应有磨砂玻璃效果
5. 计时提醒：带计时器的步骤到点后主动语音提醒，并完成震动反馈
